# TypeScript preflight

This is an environment check only. There is no coding task.

## Requirements

- Node.js 22 or newer
- npm

## Test

```bash
npm test
```

Expected result: all tests pass.

## Run

```bash
npm start
```

Then open:

```text
http://localhost:3000
```

You should see a simple **Preflight ready** page.

No code changes are required.
