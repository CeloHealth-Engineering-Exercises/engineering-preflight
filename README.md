# Celo Engineering Work Sample — Preflight

This repository is only an environment check for the Celo engineering work sample.

There is **no hidden coding task** here and **nothing in this repository is scored**.

## Clone this repository

Before Round 2, clone this public repository onto the computer you will use for the interview:

```bash
git clone https://github.com/CeloHealth-Engineering-Exercises/engineering-preflight.git
cd engineering-preflight
```

If you already cloned it earlier, pull the latest `main` before running the checks.

## Choose your interview lane

Use the language lane agreed with your interviewer:

- [TypeScript](typescript/) — requires Node.js 22.6+ and npm
- [C# / .NET](dotnet/) — requires the .NET 8 SDK

The lane README is the source of truth for the exact requirements, test command, run command, local URL, and expected result.

For your chosen lane:

1. follow its README;
2. run the documented test command and confirm the tests pass;
3. run the local application;
4. open the documented local URL in your browser.

You do not need to change, commit, push, or submit any code.

If setup fails, please resolve it or contact the interviewer before the interview so interview time is not spent on environment issues.

## After the preflight

You may keep or delete this local preflight clone. It contains only the public environment check and is not used to submit interview work.
