# Celo Engineering Work Sample — Preflight

This repository is only an environment check for the Celo engineering work sample.

There is **no hidden coding task** here and **nothing in this repository is scored**.

Use the language lane agreed with your interviewer:

- [TypeScript](typescript/)
- [C# / .NET](dotnet/)

For your chosen lane:

1. run the documented test command and confirm the tests pass;
2. run the local application;
3. open the documented local URL in your browser.

You do not need to change, commit, push, or submit any code.

If setup fails, please resolve it or contact the interviewer before the interview so interview time is not spent on environment issues.
